# dnd-tasksboard-plugin
DnD tasksboard plugin for obsidian


## How it work?
The plugin takes all notes from the folder(s) that start with -task, after which they are displayed on the task board.

## Community Plugins

To get the plugin working, you need to:

1. Find or create the folder '.obsidian/plugins' in your storage folder and copy the plugin archive into it.

2. Go to the third-party plugins section and activate the desired plugin there.

3. Create a folder with the desired marker "-tasks any text".

4. Open the board using the left panel with the table icon.
